# 我的同人｜篡改猴腳本

給 [我的同人](https://mydoujin.online/) 用的篡改猴（Tampermonkey）腳本。

| 腳本 | 檔案 |
|---|---|
| 戰報統計面板 | `mydoujin-battle-stats.user.js` |
| 戰報逐行播放 | `mydoujin-battle-playback.user.js` |

---

## 戰報統計面板

打開戰報頁時，在右下角顯示統計面板。

### 功能
- 玩家與 BOSS 的造成傷害、幸運傷害、總計傷害、承受傷害
- 回復血量、回復 SP、每人爆擊率
- 燒掉的生命上限、角色特殊迴避、中毒／出血／凍傷等異常狀態與反傷
- 自動累積逐筆傷害樣本與 BOSS 圖鑑（數值＋使用過的技能），可匯出 CSV

### 隱私
- 腳本只在 `mydoujin.online` 上執行。
- 讀取戰報時，使用你自己瀏覽器裡的登入狀態，向遊戲官方後端 `mydoujin-backend.onrender.com` 讀取戰報資料。
- 不會把任何資料送到其他網站；統計結果與圖鑑只存在你自己的瀏覽器（localStorage）。

## 戰報逐行播放

Boss 挑戰、玩家切磋／茶渡、戰報頁回放時，戰鬥過程一行一行出現，看到最後一行才知道結果。

### 功能
- 戰鬥過程逐行出現，上方顯示播放進度，可按「跳過，直接看結果」
- 播放完之前，蓋住勝利／失敗／平手標記、死亡標記、頂部死亡橫幅，以及隊伍的存活／死亡狀態
- 播完可「重播」
- 每一行後面顯示這一行被打／被補／閃開攻擊的人剩多少血（名字＋血條＋剩餘/上限）；群體治療每個被補的人各自一行、各自顯示
- 「⚙ 戰報播放」設定：
  - 逐行播放／直接顯示結果
  - 是否顯示每行剩餘血量
  - 每行間隔秒數
  - 播放時自動捲到最新一行
- 設定按鈕位置：戰報頁在「戰鬥過程」旁；Boss 頁在隊伍代碼那一列；玩家頁在「友好切磋／茶渡」上方

### 隱私
- 腳本只在 `mydoujin.online` 上執行。
- 只觀察遊戲本身的挑戰／切磋／戰報請求來決定何時開始播放，並沿用遊戲拿到的戰報資料計算剩餘血量。
- Boss 挑戰、切磋／茶渡的回傳資料裡沒有角色血量上限時，會用你自己瀏覽器裡的登入狀態，向遊戲官方後端 `mydoujin-backend.onrender.com` 讀一次該場戰報（跟戰報頁讀的是同一份）。
- 不會把任何資料送到其他網站。
- 設定只存在你自己的瀏覽器（localStorage）。
